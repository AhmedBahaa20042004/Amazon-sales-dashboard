# Amazon-sales-dashboard
📌 Project Overview

The Amazon Sales Dashboard is an interactive Business Intelligence solution developed using Power BI to analyze historical Amazon sales data (2011–2014). The dashboard transforms raw sales data into meaningful business insights through interactive visualizations, KPI tracking, and dynamic reports that support data-driven decision-making.

🚀 Objectives
Analyze overall sales performance.
Monitor revenue and profit trends.
Identify top-performing states and product categories.
Track yearly sales growth.
Support business decision-making using interactive dashboards.
🛠️ Technologies Used
Microsoft Power BI
Power Query
DAX (Data Analysis Expressions)
Data Modeling
Data Visualization
